# Журнал розробки · Іпсомнія

Внутрішня історія проєкту: як ішла розробка, які рішення ухвалені і чому. Для огляду

## Контекст

Гейміфікований тренажер розпізнавання та протидії ворожим наративам (ІПСО).
Замовник: Культурні сили. Референс методології: inoculation theory (getbadnews.com),
аналітика О. Саакяна (концепти: «гучне мовчання», «переговори як пастка», «прикладне
ворогознавство»).

Дизайн: ретро-термінал (Press Start 2P + Inter + JetBrains Mono, CRT-сканлайни,
сегментована шкала впливу). Стрічка стилізована під месенджер: фейк має виглядати як
реальний пост.

### Задача 0 — Розпил на модулі

### Задача 4 — OSINT: «Перевірити джерело» (механіка ядра)
**Статус: DONE (редизайн у Задачі 12, блок Д).**
- У фазі 1 на кожному повідомленні кнопка 🔍. Ресурс: 2 перевірки на операцію.
- Клік відкриває «профіль каналу» (дані додати в content.js до кожного повідомлення,
  поле `osint`): дата створення, що постив раніше, аномалії (різка зміна тематики,
  перейменування, синхронність з іншими каналами).
- Для ворожих каналів профіль містить червоні прапорці, для чистих — нормальну історію.
- Наскрізність: у профілях повторюваних каналів (Insider UA ← «Правда без цензури»,
  Батенко, Prawda Bez Cenzury) прямо показувати зв'язок.

Примітка: пункт про «червоні прапорці» свідомо скасований і замінений пізнішою Задачею 12
(блок Д) — профіль тепер показує тільки сирі факти без вердикту, гравець сам робить висновок.
Наскрізність збережена, але через `nameHistory`/`repostedBy`, а не окреме поле `link`.
Дрібна нестиковка в копірайтингу: фінальний екран (`finale()`) досі описує OSINT як
«профіль каналу за ціну часу на таймері» — насправді це ліміт кількості перевірок
(2 на операцію, 3 у боса), не таймер. Текст рекламного блоку не оновили після зміни механіки.

### Задача 5 — Ранг за операцію (A/B/C)
**Статус: DONE (шкалу переглянуто в Задачі 12, блок В).**
Після дебрифу кожної операції — оцінка з розбивкою: розпізнавання (чисто/промахи/хибні),
аналіз техніки (так/ні), контрхід (оптимальний/середній/шкідливий), швидкість
(лишок таймера, інформаційно). Показувати піксельною літерою + пропозиція
«перепройти операцію» (рестарт поточної операції без скидання кампанії).
Примітка: початкова шкала була S/A/B/C зі швидкістю як критерієм найвищого рангу.
Задача 12 (блок В7) свідомо прибрала S: тепер A/B/C, де ранг залежить від кількості
помилок (0/1/2+), швидкість — довідкова інформація, не критерій рангу.

## Правила контенту (для будь-яких текстів у грі)

- Жива українська. Без довгих тире «—» у текстах постів і відповідей. Пости в стрічці
  різної довжини; побутові чати можуть бути з малої літери.
- Тонкі наративи не брешуть прямо — вони інсинуюють («нічого не стверджую»,
  «питання лишаю відкритим», «Україну можна зрозуміти, але...»).
- Пастки — це щирі емоційні пости без вигаданих фактів. Пояснення (`w`) обов'язкове.
- Кожна відповідь має поле пояснення — це навчальне ядро, не скорочувати.
- Реальні події можна використовувати як типажі ситуацій, але без вигаданих фактів,
  поданих як реальні, і без реальних імен приватних осіб.
